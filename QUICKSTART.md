# Быстрый старт

До кода агент должен установить цель конкретного продукта и наблюдаемые критерии. Если их нет — задаёт вопрос и ждёт ответа. Для серии один пример не заменяет отдельные разные концепты. Уже подтверждённая цель повторного опроса не требует.

## Новый проект

1. Скачайте комплект и сохраните его рядом с отдельной папкой проекта.
2. Откройте проект в среде ИИ-агента с чтением файлов и запуском кода.
3. Дайте доступ к комплекту и вставьте запрос ниже.

> Прочитай TVORETS.md. Используй Творца для создания [продукт]. Пользователь — [кто]. Главная задача — [действие и результат]. Начни с самого короткого работающего пути. Обычные технические решения принимай самостоятельно. Проверь собственный ввод, ошибки, сохранение и повторный запуск. Покажи результат и назови непроверенное.

Если нужна публикация или внешняя интеграция, назовите разрешённые действия и ограничения отдельно. Не передавайте пароли в текст запроса.

## Уже существующий продукт

> Прочитай TVORETS.md и AUTONOMOUS-REPAIR.md. Изучи проект и воспроизведи [проблему]. Сохрани данные и работающие функции. Найди причину, исправь её и повтори исходный сценарий. Покажи доказательства и остаточные ограничения.

## Улучшить понятность интерфейса

> Используй Творца. Главная задача пользователя — [задача]. Открой текущие экраны, проверь основной путь и убери лишние решения. Покажи рабочий вариант с ясным следующим действием. Проверь узкий экран и собственные данные. Не считай декоративную анимацию доказательством работы.

## Навык Codex

Скопируйте папку `skill/tvorets` в пользовательский каталог навыков Codex — обычно `~/.codex/skills/tvorets`. При обновлении сохраните собственные изменения старой версии. Обновите обнаружение навыков способом, доступным в вашей среде, и вызовите `$tvorets`.

Если установка недоступна, передайте `TVORETS.md` напрямую. Совместимость другой агентной среды нужно проверять отдельно; наличие Markdown не означает выполненную установку.

## Контроль перед передачей

Откройте сам выдаваемый продукт из новой папки и повторите главное действие. Проверьте, что приложены нужные файлы и понятный запуск. Для сложного проекта заполните `PROJECT-STATE.template.md`. Для утилиты доказательств нужен Python 3.9 или новее:

```sh
python tests/test_evidence.py
python scripts/check_evidence.py --help
```

Утилита проверяет ссылки на файлы и их хеши. Она не исполняет тесты из записи и не разрешает релиз. Подробности — `EVIDENCE.md`.
