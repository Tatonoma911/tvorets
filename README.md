# Творец

### От идеи до результата. С управлением всей работой.

[English](README.en.md) · **Русский** · [Быстрый старт](QUICKSTART.md)

Вы описываете, что хотите получить. **Творец организует работу ИИ-агента:** уточняет цель, выбирает подход, сочетает навыки и инструменты, выстраивает последовательность, создаёт результат и проверяет его.

Сайт, игра, CRM, бот, презентация, маркетинговая задача — для каждого результата нужен свой путь. Творец собирает его под вашу задачу и сохраняет управление до передачи работы.

Автор: **Антон Казаков · [@kazakovant](https://t.me/kazakovant)**

## Начните с вашей задачи

> «У меня ремонтная компания. Клиенты просят дополнительные работы голосовыми сообщениями. Хочу разбирать просьбу, сверять с исходной сметой и готовить изменение на согласование».

Творец должен разобраться в процессе, определить нужные данные, собрать понятный пользовательский путь, выбрать средства и проверить результат. Обычные технические решения остаются у агента. Существенные вопросы о цели и полномочиях — у владельца.

Можно прийти с описанием, наброском, референсом или существующим проектом. Если конкретная цель неизвестна, Творец сначала помогает её выяснить.

## Что делает этот подход сильным

### Одна цель объединяет инструменты

Дизайн, код, анимация, редактура и тестирование получают конкретные участки. Творец отвечает за то, чтобы их результаты сошлись в работающий продукт. Специалисты сохраняют свою профессиональную роль внутри общего процесса.

### Важен порядок исполнения

Каждый существенный шаг получает входные данные, создаёт выход и проходит проверку перед передачей дальше. Независимые части можно делать параллельно. Если меняется исходник, пересматриваются затронутые зависимости.

```text
Задача бизнеса → пользовательский путь → данные и логика
              → интерфейс → уместная анимация → проверка в браузере
```

Это пример. Для игры, исследования или презентации последовательность будет другой.

### Разные подходы можно сочетать

Frontend Design помогает с композицией, UI/UX Pro Max — с взаимодействием, Impeccable — с разбором интерфейса, навыки Эмиля Ковальского — с движением, Humanizer — с текстом, Playwright — с браузерной проверкой. Творец выбирает вклад каждого средства по задаче и фактической доступности.

Отсутствующий навык не закрывает направление: агент может изучить источники и собрать необходимый процесс. Бренд, формат и цель владельца сохраняются при смене инструментов. Перечень маршрутов открыт для новых задач и сочетаний.

### Работа продолжается через ошибки и перерывы

Творец направляет агента воспроизвести проблему, найти причину, исправить и повторно проверить сценарий. Состояние проекта сохраняет принятые решения, версию, проверки и следующий шаг. После паузы можно продолжить работу с актуального состояния.

## Что можно поручить

| Задача | Какой результат проверять |
|---|---|
| Сайт или приложение | Основной пользовательский путь, собственный ввод, состояния и мобильный экран |
| Игра | Играбельный цикл, управление, обратную связь и повторный запуск |
| CRM или внутренний сервис | Операции с данными, связи, сохранение и необходимые права |
| Бот или автоматизация | Путь от реального события до полезного ответа или действия |
| Маркетинг | Обоснованное предложение, готовые материалы и работающий путь заявки |
| Презентация или документ | Нужный формат, содержание, читаемость и открываемый файл |
| Таблица или дашборд | Проверяемые расчёты, источники и полезный вывод |

## Запуск за минуту

1. [Скачайте комплект](https://github.com/Tatonoma911/tvorets/archive/refs/heads/main.zip).
2. Откройте папку проекта в среде ИИ-агента с доступом к файлам и нужным инструментам.
3. Передайте агенту запрос:

```text
Прочитай TVORETS.md и работай как Творец.
Хочу сделать [что] для [кого], чтобы [действие и полезный результат].
Критерий успеха: [что я смогу открыть, выполнить или проверить].
Сам организуй работу, сочетай подходящие навыки и инструменты,
принимай обычные технические решения и проверяй результат.
Если существенной информации не хватает, изучи имеющиеся материалы,
затем задай точный вопрос. Покажи результат и укажи непроверенное.
```

В Codex можно установить папку `skill/tvorets` как пользовательский навык и вызвать `$tvorets`. [Подробности и примеры](QUICKSTART.md).

## Что проверено

Для версии **1.7** независимо сверены восемь найденных конфликтов инструкций, последовательность зависимостей и сочетание средств. Проверены ссылки и согласованность копий. В комплекте есть **13 повторяемых тестов утилиты целостности доказательств**:

```sh
python tests/test_evidence.py
```

[Отчёт 1.7](TEST-RESULTS-1.7.md) указывает точный охват. Эти проверки относятся к инструкциям и утилите; каждый создаваемый продукт проходит собственную проверку. Сравнение производительности с другими системами и полный прогон всех сочетаний навыков не проводились.
