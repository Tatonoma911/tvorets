# Доказательства и передача

Сохраняй наблюдаемый результат, версию исходников, шаги/команду, окружение, дату, ожидаемое и фактическое, статус и ограничения. Для небольшого изменения достаточно краткой записи; для сложного проекта полезен машинный манифест.

Для визуального доказательства различай запрошенный viewport, фактическую CSS-геометрию и размер сохранённого PNG. После изменения размера дождись наблюдаемого обновления средствами браузера и проверь снимок. Скриншот может быть уменьшен или обрезан инструментом; такой файл не подтверждает заявленные размеры сам по себе. Запиши масштабирование/обрезку, если они известны; при расхождении сохрани исходное доказательство и сделай проверенный повтор, не переименовывай его в PASS.

`scripts/check_evidence.py MANIFEST --root PROJECT` проверяет **целостность записи**, а не качество продукта: обязательные проверки должны иметь PASS, критерий и непустые доказательства с SHA-256, файлы версии должны совпасть. Скрипт не запускает команды из JSON, не читает за пределами root и не удостоверяет правдивость авторских утверждений. После него всё равно нужны настоящий тест и просмотр результата. Возвращаемый `EVIDENCE_CONSISTENT` не означает «релиз одобрен».

Минимальный формат (замени условные пути/хэши фактическими):

```json
{
  "schema_version": 1,
  "sources": [{"path": "src/app.js", "sha256": "64 hexadecimal characters"}],
  "checks": [{
    "id": "reset-late-photo",
    "required": true,
    "status": "PASS",
    "kind": "runtime",
    "criterion": "После сброса позднее фото не возвращается",
    "evidence": [{"path": "qa/reset-log.txt", "sha256": "64 hexadecimal characters"}]
  }]
}
```

В `sources` включи изменённые исходники, тесты и значимые конфигурации; неполный список не позволяет заявлять свежесть всего проекта. Для уже опубликованного продукта добавь в отчёт ссылку, идентификатор деплоя и проверенный live-сценарий. Проверяй сам выдаваемый архив после распаковки в чистую папку. Установленный навык, standalone-файл и комплект не должны расходиться по правилам и версии.

Пользователю передай результат и конкретные пределы: «этот сценарий проверен в Chromium при 390×844» вместо «всё работает везде». Владелец принимает смысл и творческое направление; агент самостоятельно отвечает за доступные технические проверки и исправления. Поддержка будущих проектов требует запуска навыка в новой рабочей среде; скрытого фонового контроля нет.
